# MissionNext

A career transition platform built for veterans — evaluate job offers, generate tailored resumes, track applications, and discover opportunities.

Designed to be model-agnostic: bring your own API key from Anthropic, OpenAI, or Google Gemini.

## Features

- 🎯 Job scoring and evaluation (A-F rating system)
- 📄 AI-powered tailored CV/resume generation
- 📋 Application tracker
- 🔍 Job portal scanner

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js + TypeScript
- Tailwind CSS
- Model-agnostic AI layer (Claude, GPT-4o, Gemini)
